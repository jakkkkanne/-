# Threads 投稿の叩き台（11月・10本）

コンセプト: 育児の"困った"を、モノとアイデアで5分ラクにする
発信者: 2歳男児・6歳女児のパパ
11月のテーマ: 寒さ対策／就学前の準備／イヤイヤ期／年末の片付け

> 使い方: 【 】部分を自分の体験に差し替える。実際に使っていないグッズは紹介しない

## 1. 困り事→解決（寒い朝）
```
寒くなってから、朝布団から出てこない問題。

うちは「着替えを布団の中で温めておく」作戦にしました。
前の晩に枕元へ置いておくだけ。

冷たい服を嫌がって泣くのが減って、
朝の5分が戻ってきました。
```

## 2. 0円アイデア（イヤイヤ期）
```
2歳のイヤイヤ期、
「〇〇しなさい」より効いた言い方。

✕「早く靴はいて」
○「赤い靴と青い靴、どっちで行く？」

選ばせるだけで、自分から動いてくれることが増えました。
パパの声かけ、ちょっと変えるだけで全然違う。
```

## 3. 質問（就学前）
```
6歳の娘、来年から小学生。
ランドセル選び、正直よくわかってません…

先輩パパママ、
「これは見ておけばよかった」ってポイントありますか？
```

```

それから【練習した方法／使ったグッズ】で
今では朝3分で結べるように。

できないパパ、意外と多いはず。
```

## 6. 0円アイデア（片付け）
```
おもちゃの片付けが終わらない問題。

「全部片付けて」ではなく
「青いのだけ箱に入れて！」と色で区切ったら、
2歳でもゲーム感覚でやってくれました。

6歳の娘には「タイマー3分勝負」。
年齢で声かけを変えるのがコツでした。
```

## 7. 共感（ワンシーン）
```
上の子が「赤ちゃんみたいに抱っこして」と言ってきた日。

下の子が生まれてから、
我慢してたんだなと気づきました。

今は寝る前の5分だけ「娘だけの時間」を作っています。
```

## 8. 困り事→解決（風邪シーズン）
```
冬になると、2人とも鼻水が止まらない季節。

うちで助かっているのは【加湿・鼻水ケアの工夫やグッズ】。

小さい子の風邪対策、
みなさんの家で効いたものがあれば教えてください。
```
