## 投稿

### Day1（火 10/14）自己紹介
```
はじめまして。2歳の息子と6歳の娘のパパです。

イヤイヤ期と、もうすぐ小学生。
毎日バタバタですが、ちょっとした道具や工夫で
「5分ラクになった」ことがけっこうあります。

そんな育児の"困った"の解決法を発信していきます。
同じくらいの子がいる方、ぜひ仲良くしてください🙌
```

### Day2（水 10/15）困り事→解決
```
2歳のイヤイヤ期、朝の着替えが一番の戦場でした。

うちで効いたのは「服を2択で選ばせる」こと。
前の晩に2セット並べておいて
「どっちにする？」と聞くだけ。

自分で選んだ服だと、意外とすんなり着てくれます。
完璧じゃないけど、朝の格闘が半分になりました。
```

### Day3（木 10/16）質問
```
6歳の娘、来年から小学生です。

先輩パパママに聞きたいのですが
入学前に「準備しておいてよかった」ことって何でしたか？

モノでも習慣でも、何でも教えてもらえると嬉しいです🙏
```

### Day4（金 10/17）0円アイデア
```
保育園の着替え準備、
前の晩に「1日分ずつ袋にまとめる」だけで朝がラクになりました。

ジップ袋に曜日を書いておくと
ママがいない日でも迷わず持たせられる。

パパが準備を担当するときこそおすすめです。
```

### Day6（日 10/19）パパ目線の失敗談
```
パパあるある、だと思いたい失敗。

公園に2人連れて行ったら
息子のオムツ替えセット、丸ごと忘れました。

それ以来、玄関に「お出かけセット」を常備。

忘れ物ゼロになりました。
```
