# Etsy 日本テーマ デジタル商品

Threads自動化プロジェクトとは別の、Etsy販売用デジタル商品の制作ブランチです。

| ファイル | 内容 |
|---|---|
| `01_year_of_sheep_2027` | 2027年 未年ウォールアート・年賀カード・干支早見表 |
| `02_hiragana_workbook` | ひらがな練習帳(Lesson 1 あいうえお) |
| `03_sashiko_patterns` | 刺し子パターン集(表紙・青海波・十字刺し) |

各 `.html` が元データ、`.pdf` が販売用ファイル、`preview_*.png` が確認用画像です。
HTMLを編集したら Playwright(Chromium)でA4 PDFに書き出します。
